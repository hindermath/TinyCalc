# Kompakte Agenten-Einstiege / Compact agent entry files

## Problem / Problem

DE: Codex kann einen Teil der bisherigen Agentenregeln wegen des Dateibudgets
abschneiden. EN: Codex can truncate some guidance because of its document budget.

## Lösung / Solution

DE: Die fünf Einstiege behalten verbindliche Projektregeln und maschinell
gelesene Blöcke. Die [Detailreferenz](agent-guidance.md) enthält die Vertiefung.
EN: The five entry files retain project rules and machine-read blocks. The
[detailed guidance](agent-guidance.md) contains supporting material.

## Prüfung und Risiko / Checks and risk

DE: Dateigrößen, Ladeketten, Links, Marker und Agentenparität wurden geprüft.
Das verbleibende Risiko sind aufgabenspezifische Regeln, deren Referenz beim
Einstieg übersehen wird. Der Einstieg verlangt das Lesen der passenden Abschnitte.
EN: File sizes, loading chains, links, markers and agent parity were checked.
Readers may miss task-specific material. The entry files direct them to the
relevant sections before work.
