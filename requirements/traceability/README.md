# Requirements Traceability

Jeder aktive Intake benötigt einen aktuellen normalisierten SHA-256-Wert, ein
Intake-Receipt und genau einen Eintrag in der kanonischen Serie. Vorgänger
bleiben unter `history/` erhalten. Historische Evidence wird nicht mechanisch
umgeschrieben.

*Every active intake needs a current normalized SHA-256 value, an intake
receipt, and exactly one canonical-series entry. Predecessors remain under
`history/`. Historical evidence is not rewritten mechanically.*
