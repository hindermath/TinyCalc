byte-for-byte. They are not the current series and start no run. The unchanged
order/report were copied from requirements/intakes/series/tinycalc-delivery;
their relative links still use that original base. They must not be rewritten
because provenance/supersession hashes bind their exact bytes. Use this
companion navigation instead. Snapshot evidence and the preceding review are
linked above through valid local paths.

The table maps all 13 historical members in their original order. Eight updated
contracts link only to their predecessor History snapshots, not newer active
contracts. Five unchanged members use immutable pre-PR Git links. The local
manifest binds their identities, positions and hashes. The three historic feature
links point to existing local directories; other members had no feature link.
This readable companion fixes navigation without changing archived evidence,
requirements, statuses, dependency edges or delivery authority.
